# TO Client

TO Client is an independent native Android VPN client with an Xray-first core,
Android `VpnService`, replaceable TUN bridge, encrypted profile/subscription
persistence, DNS and routing policies, live traffic counters, diagnostics, and
an original bilingual native interface.

Build instructions are in [BUILD.md](BUILD.md). Third-party dependency and
license information is under `third_party/`.

Physical-device VPN validation is explicitly deferred; no unexecuted device
result is claimed.
